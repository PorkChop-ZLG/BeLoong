# docs 文件夹说明

本文档用于说明 `docs` 文件夹的定位、目录规则和文件管理要求。

## 1. 文件夹作用

`docs` 文件夹主要用于保存本整合包的设计文档。

除正式设计文档外，也可以用于保存：

- 各种草稿
- 工具脚本或工具说明
- 表格（如数值表、统计表）
- 配置参考 / 配置变更清单
- 其他与整合包开发相关的辅助资料

## 2. `plans` 文件夹规则

`plans` 文件夹**专门用于 AI 智能体存放文档**，例如：

- AI 生成的设计方案
- AI 生成的实施计划
- AI 生成的过程记录

**手写文档不能放入 `plans` 文件夹。**

## 3. `designs`文件夹规则

`designs`文件夹只能存放**正式的设计文档**。

正式设计文档必须满足以下要求：

- 内容已确认、已评审或已批准。
- 与整合包的实际修改保持同步：文档描述的方案、数值、结构或配置，应与当前整合包中的实际状态一致。
- 如果整合包实际修改发生变化，需要同步更新对应的正式设计文档。

---

## 目录约定速查

| 路径 | 用途 | 是否允许手写文档 |
|---|---|---|
| `docs/designs/` | 正式设计文档 | 是，但正式文档需与整合包同步 |
| `docs/plans/` | AI 智能体专用文档 | 否，AI 智能体生成 |
