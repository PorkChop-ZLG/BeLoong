# 龙之生存·成长阶段总结（以洞穴龙为例）

> 数据来源：`kubejs/data/dragonsurvival/dragonsurvival/dragon_stage/`
> 机制依据：DS 2.0.69 源码 `DSModifiers.java:60`、`AttributeModifierSupplier.java`、`Modifier.java`
>
> 本文只陈述**当前整合包的实际数值**，不做设计评价。

## 一、六阶段总览

整合包把 DS 原版的三阶段（`newborn 10-25` / `young 25-40` / `adult 40-60`，成长上限 **60**）
重做为**成长 20 → 300 的连续六阶段链**。

| # | 阶段 ID | 中文 | 成长区间 | 区间宽度 | 自然成长耗时 | 小时 | 游戏日 | 年龄设定 |
|---|---|---|---|---|---|---|---|---|
| 1 | `dragonsurvival:newborn` | 幼年 | **10 – 50** | 40 | 432,000 ticks | 6 | 18 | 0 ~ 6 岁 |
| 2 | `dragonsurvival:young` | 青年 | 50 – 100 | 50 | 1,728,000 ticks | 24 | 72 | 6 ~ 30 岁 |
| 3 | `dragonsurvival:adult` | 成年 | 100 – 150 | 50 | 5,184,000 ticks | 72（3 天） | 216 | 30 ~ 100 岁 |
| 4 | `dragonsurvival:cave_ancient` | 远古 | 150 – 200 | 50 | 51,840,000 ticks | 720（1 月） | 2160 | 100 ~ 800 岁 |
| 5 | `dragonsurvival:cave_archean` | 太古 | 200 – 250 | 50 | 155,520,000 ticks | 2160（3 月） | 6480 | 800 ~ 3000 岁 |
| 6 | `dragonsurvival:cave_progenitor` | 始祖 | 250 – 300 | 50 | 622,080,000 ticks | 8640（12 月） | 25920 | 3000 ~ 10000 岁 |
| — | `*_human`（化形） | 化形 | 100 – 300 | 200 | — | — | — | — |

> 📌 **幼年已由 `20–50` 改为 `10–50`**（宽度 30 → 40）。
> 连带影响：幼年阶段的四个「随成长变化」的属性**改为 `precise_base`/`precise_amount`**，
> 使起点（成长 10）与终点（成长 50）仍精确落在权威表数值上（见 §3.4）。
> 只改了共享的 `newborn.json`，受影响的物种为**洞穴龙 / 森林龙 / 海洋龙 / 苔原龙**；
> 其余附属自带起始阶段（`aether_child` 等，均为 20–50），未受影响。

**身高**（格）：`1.8~2.7` → `2.7~3.6` → `3.6~5.4` → `5.4~7.2` → `7.2~1.8` → `1.8` → 化形 `1.8`

> **太古 → 始祖体型回缩是刻意设计**：始祖龙形体会**回到 1.8 格（原版身高）**，
> 与"化形"形态同高。`cave_archean` 的 `scale` 增量 `-0.054·lv` 正是为此服务，
> 使体型从 3.60 平滑降到 0.90（`0.90 × 2.0 = 1.8` 格）。

**连续性**：区间首尾严格相接（50/50、100/100、150/150、200/200、250/250）。
DS 会强校验默认阶段的连续性（`DragonStage.validate`），区间不连续会直接崩启动。

**默认阶段标记**：前三个阶段 `is_default: true`，后三个 `false`。
后三个阶段通过 `dragon_species/cave_dragon.json` 的 `custom_stage_progression`
挂到洞穴龙身上。

> ⚠️ `1 游戏日 = 24,000 ticks`。上表"自然成长耗时"是**该阶段内**从区间下限涨到上限
> 所需的时间（`ticks_until_grown`）；靠 `growth_items` 加速可大幅缩短。

## 二、成长条件

### 2.1 自然成长

阶段内每 tick 按固定速率增长（`DragonStage.ticksToGrowth`）：

```
每 tick 增长 = (区间上限 - 区间下限) / ticks_until_grown
```

以洞穴龙为例，各阶段每 tick 增长量：

| 阶段 | 计算式 | 每 tick 增长 | 每小时（72000 ticks） |
|---|---|---|---|
| 幼年 | **40** / 432,000 | 0.0000926 | ≈ 6.67 |
| 青年 | 50 / 1,728,000 | 0.0000289 | ≈ 2.08 |
| 成年 | 50 / 5,184,000 | 0.0000096 | ≈ 0.69 |
| 远古 | 50 / 51,840,000 | 0.00000096 | ≈ 0.069 |
| 太古 | 50 / 155,520,000 | 0.00000032 | ≈ 0.023 |
| 始祖 | 50 / 622,080,000 | 0.00000008 | ≈ 0.0058 |

> 幼年区间由 30 宽改为 **40 宽**，而 `ticks_until_grown` 仍为 432,000，
> 所以**幼年阶段涨满所需时间不变（6 小时），但每 tick 涨得更多**（覆盖 40 点而非 30 点）。

⇒ 越往后**自然成长越慢**，必须依赖成长道具。

**读法**（源码 `GrowthItem`）：

- `growth_in_ticks` **为正** ⇒ 吃一个**立即增加**这么多成长
- `growth_in_ticks` **为负** ⇒ 吃一个**立即减少**（此处 `star_bone` 是统一的"退化/降级"道具）
- `growth_in_ticks = 0` ⇒ **切换自然成长开关**（吃掉即暂停/恢复自然成长），不改变成长值

`maximum_usages` 全部为默认值 `-1`（无限次使用）。

**材料递进链**（本整合包自制道具 `kubejs:` 在远古阶段开始接管）：

```
远古龙骨 → 龙心碎片 → 脆弱龙心 → 远古龙心 → 洞穴龙心(kubejs) → 始祖龙心(kubejs)
                      ↑ 幼年       ↑ 青年     ↑ 成年        ↑ 远古/太古/始祖
```

### 2.3 自然成长停止条件

六个阶段**全部**带同一条件：

```json
"is_natural_growth_stopped": {
  "type_specific": {
    "type": "dragonsurvival:dragon_predicate",
    "is_growth_stopped": true
  }
}
```

⇒ 该条件成立时自然成长暂停（配合 `star_heart` 的手动开关）。

## 三、数值改变

### 3.1 等级参数怎么算（关键）

所有阶段修饰符的 `amount` 都是一个**以"阶段内进度"为等级**的提供器。
源码（`DSModifiers.java:60`）：

```java
handler.stage().value().applyModifiers(player,
        handler.getGrowth() - handler.stage().value().growthRange().min());
```

⇒ **`lv = 当前成长 − 本阶段区间下限`**

| 阶段 | `lv` 取值范围 |
|---|---|
| 幼年 | 0 – 30 |
| 青年 | 0 – 50 |
| 成年 | 0 – 50 |
| 远古 | 0 – 50 |
| 太古 | 0 – 50 |
| 始祖 | 0 – 50 |

⚠️ **`lv` 起点是 0，不是 1。** 进入新阶段时 `lv = 0`，到本阶段上限时 `lv = 区间宽度`。

两种提供器的取整行为不同（`Modifier.java:59-61`）：

| 提供器 | 公式 | 取整 |
|---|---|---|
| `linear` / `lookup` 等 `LevelBasedValue` | `base + per_level_above_first × (lv − 1)` | **`lv` 先截断为 int** |
| `precise_base` / `precise_amount` | `precise_base + precise_amount × lv` | **保留 double，不截断** |

⇒ 本包用 `precise_*` 的属性（`generic.scale`）在阶段内**连续变化**；
用 `linear` 的属性按 `lv` 的整数台阶跳变。

### 3.4 幼年起始值改动（10 – 50）

整合包把**幼年区间由 `20–50` 改为 `10–50`**，宽度 30 → **40**。
只改了 `newborn.json`，且要求**起点（成长 10）与终点（成长 50）的实际值仍与权威表一致**。

#### 为什么必须改用 `precise_*`

区间变宽后，「每级增量」变成小数：

| 属性 | 修饰符起点 | 修饰符终点 | 每级增量 | `linear` 能否精确命中 |
|---|---|---|---|---|
| `generic.scale` | -0.1 | 0.35 | **0.01125** | ✗ 非整数 |
| `generic.max_health` | 0 | 30 | **0.75** | ✗ 非整数 |
| `generic.attack_damage` | 0 | 1.5 | **0.0375** | ✗ 非整数 |
| `dragonsurvival:dragon_breath_range` | 1.5 | 3.0 | **0.0375** | ✗ 非整数 |

`linear` 的 `lv` 会被截断成 int（§3.1），所以 `per_level_above_first` 必须取整，
**无法同时命中起终点**。因此这四个属性改为 `precise_base` / `precise_amount`（保留 double）。

> 其余 7 个属性是**阶段内常数**（护甲韧性 / 速度 / 跳跃 / 行走高度 / 安全摔落 / 两个交互距离），
> 不随 `lv` 变化，**无需改动**。

#### 改动后的 `newborn.json` 修饰符

| 属性 | 原（20–50） | 新（10–50） |
|---|---|---|
| `generic.scale` | `precise_base -0.1` / `precise_amount 0.015` | `precise_base -0.1` / `precise_amount 0.01125` |
| `generic.max_health` | `linear base 1.0` / `per 1.0` | `precise_base 0.0` / `precise_amount 0.75` |
| `generic.attack_damage` | `linear base 0.05` / `per 0.05` | `precise_base 0.0` / `precise_amount 0.0375` |
| `dragonsurvival:dragon_breath_range` | `linear base 1.55` / `per 0.05` | `precise_base 1.5` / `precise_amount 0.0375` |

|---|---|
| 洞穴龙 `cave_dragon`、森林龙 `forest_dragon`、海洋龙 `sea_dragon`、苔原龙 `tundra_dragon` | 以太龙 `aether_child`、机械龙 `annihilator_type_a_00`、晶咒龙 `crystcursed_newborn`、地皇龙 `dihuang_newborn`、夜煞 `night_striker_newborn`、翼麒麟 `kirin_newborn`（自带起始阶段，均仍为 20–50）；星界龙 `protostar`、星辰龙 `stardust`（独立阶段体系） |

> 上表「不受影响」的附属起始阶段若也要改成 10–50，需**各自单独修改**，
> 并按本节同样的方式改用 `precise_*`。

### 3.5 阶段专属能力：大型破坏（`destruction_data`）

后三个阶段解锁「大型龙体破坏地形」，前三个阶段**没有**（`destruction_data` 缺失 ⇒ 不能破坏）。

| 阶段 | 方块破坏成长阈值 | 碾压成长阈值 | 碾压伤害系数 | 可破坏方块 |
|---|---|---|---|---|
| 幼年 / 青年 / 成年 | — | — | — | 无 |
| **远古** | 150 | 150 | 0.04 | `#dragonsurvival:large_dragon_destructible` |
| **太古** | 200 | 200 | 0.05 | 同上 |
| **始祖** | 250 | 250 | 0.05 | 同上 |

阈值恰好等于本阶段区间下限 ⇒ **一进入该阶段就立即解锁**。
DS 会校验这两个阈值必须落在本阶段区间内（`DragonStage.validate`）。

## 四、字段速查（写新阶段时用）

```jsonc
{
  "is_default": false,                 // 是否属于默认三阶段链
  "growth_range": { "min": 150.0, "max": 200.0 },   // 必需，min>=1 且 max>min
  "ticks_until_grown": 51840000,       // 必需，intRange(1, 365天)
  "modifiers": [ /* Modifier[] */ ],   // 默认 []
  "growth_items": [ /* GrowthItem[] */ ],  // 默认 []
  "is_natural_growth_stopped": { /* EntityPredicate */ },   // 可选
  "destruction_data": { /* DestructionData */ }             // 可选
}
```

**`GrowthItem`**

```jsonc
{ "items": "kubejs:cave_dragon_heart",   // id 列表 或 #tag
  "growth_in_ticks": 864000,             // 正=加成长，负=减成长，0=切换自然成长开关
  "maximum_usages": -1 }                 // 默认 -1 = 无限
```

**`Modifier`**

```jsonc
{ "attribute": "minecraft:generic.scale",
  "amount": { "precise_base": 1.7, "precise_amount": 0.018 },  // 或 LevelBasedValue
  "operation": "add_value" }
```

**`DestructionData`**

```jsonc
{ "block_destruction_growth": 150.0,   // 必须落在本阶段区间内
  "crushing_growth": 150.0,            // 同上
  "crushing_damage_scalar": 0.04,
  "block_predicate": { "type": "minecraft:matching_block_tag",
                       "tag": "dragonsurvival:large_dragon_destructible" },
  "entity_predicate": {} }
```
